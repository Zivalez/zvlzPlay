## What is CloudStream?

**CloudStream** is an open-source Android app for watching movies, anime, drama, and TV series for free, with no ads and no account required.

CloudStream does not provide any built-in content, it only functions as a player and search engine. To start watching, you need to install **extensions (plugins)** that fetch video data from various streaming websites.


## What is zvlzPlay?

**zvlzPlay** is a collection of extensions/providers for CloudStream that supports various Indonesian and international streaming sites.

> **CloudStream** = the app (container)\
> **zvlzPlay** = extensions to get streaming content


## Features

- Ad-free
- No tracking/analytics
- Bookmarks
- Phone and TV support
- Chromecast
- Skip opening
- No login required
- Switch between providers as needed
- Resolution depends on provider (most support 1080p and above)
- Universal search, the more providers installed, the more complete the results

## How to Install zvlzPlay Extensions

1. Install the CloudStream app first.\
   After installation, the app will appear empty because no extensions are installed yet.
2. Open `Settings`.
3. Go to `Extensions`.
4. Select `Add Repository`.
5. Enter the following URL as the Repository URL:
```
https://cloudstream.zvlz.my.id/builds/repo.json
```
6. The repository name can be left empty or filled in as you like (e.g., `zvlzPlay`).
7. Once the repository is added, open **zvlzPlay** and select the providers you want to use.
8. Go back to the **Home Screen**, then select a provider in the bottom right corner.
9. Done, enjoy watching.

## FAQ

### Why is the app empty after installation?
CloudStream requires extensions (repository) first. Follow the steps in the [How to Install](#how-to-install-zvlzplay-extensions) section to add a repository.

### Which provider is best for Anime?
- **Samehadaku** : most complete with the fastest streaming
- **Kuramanime** : fastest updates and stable
- **Otakudesu**, **Alqanime**, **Nontonanimeid**, **Kuronime**, **Gomunime** : other alternatives

### Which provider for Drama and Movies?
- **Idlix** : most complete
- **LayarKaca**, **Funmovieslix**, **Pencurimovie**, **Moviebox**

### Is Donghua available?
- **Kuramanime** and **Winbu** provide Donghua content.

### Can I watch Indonesian live TV (Indosiar, RCTI, SCTV, etc.)?
Yes. Install the **IPTV** provider from the extension list. Popular Indonesian channels are available in the "Popular" row, the rest are grouped by category (News, Sports, Kids, etc.).

### Can I watch Twitch streamers?
Yes. Install the **Twitch** provider from the extension list.

### Why does search return no results?
- Make sure providers are installed.
- In the search section, set the provider filter and enable all provider types.
- The more providers installed, the more complete the search results.
